# My Personal Portfolio

![Portfolio Screenshot](link-to-your-screenshot.png) 

This is the repository for my personal portfolio, built to showcase my projects and skills as an AI Engineer. The site is built with modern web technologies, focusing on performance, interactivity, and a clean user experience.

### [🚀 View Live Site](https://your-portfolio-url.com) 

---

## ✨ Features

- **Blazing Fast Performance:** Built with Next.js for Static Site Generation (SSG).
- **Interactive AI Demos:** Users can interact with live machine learning models directly in the browser via API Routes.
- **Responsive Design:** Fully responsive layout for all devices, styled with Tailwind CSS.
- **Clean Codebase:** Written in TypeScript for type safety and maintainability.
- **SEO Optimized:** Structured for search engines to easily find and index.

---

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Deployment:** [Vercel](https://vercel.com/)
- **AI Model Execution:** Python scripts run via Node.js `child_process`.
